## 🖨️ PRINT METHOD SPECIFICATIONS

### **DTG (Direct-to-Garment) - Recommended**

**Advantages:**
- High detail
- Full color
- Soft hand feel
- Good for small runs

**Specifications:**
- **File Format:** PNG (transparent background) or PDF
- **Resolution:** 300 DPI minimum
- **Color Mode:** RGB (converted to print colors)
- **Bleed:** Not required (DTG prints exact size)
- **White Underbase:** Required for dark garments

**File Requirements:**
- Separate file for front print
- Separate file for back print (if applicable)
- Transparent background (PNG)
- Or white background with clear print area (PDF)

---

### **Screen Print (Alternative)**

**Advantages:**
- Durable
- Cost-effective for larger runs
- Bold colors

**Specifications:**
- **File Format:** Vector (AI, EPS) or high-res raster (PNG, PDF)
- **Resolution:** 300 DPI minimum
- **Color Mode:** Spot colors (Pantone) or CMYK
- **Separations:** One file per color
- **Bleed:** 0.125" (3mm) on all sides

**File Requirements:**
- Color separations (if multi-color)
- Registration marks
- Cut lines
- Print area clearly defined

## 📏 MEASUREMENT GUIDE

### **Print Area Dimensions:**

```
FRONT PRINT:
- Width: 4-5" (depending on line)
- Height: 1.5-2" (depending on line)
- Top edge: 2" below neckline seam
- Center alignment: Vertical center of garment

BACK PRINT (if applicable):
- Width: 8" max
- Height: 3" max
- Top edge: 6" below neckline seam
- Center alignment: Vertical center of garment
```

### **Safe Zone:**
- Keep important text/graphics 0.25" inside print area
- Avoid edges where print may fade
- Account for garment stretch
