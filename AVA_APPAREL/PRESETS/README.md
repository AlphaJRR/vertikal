# AVA Apparel - Adobe Preset Files

## Installation Instructions

### Lightroom Classic:
1. Open Lightroom
2. Go to Develop module
3. Right-click on Presets panel
4. Select "Import"
5. Choose the `.lrtemplate` or `.xmp` file
6. Preset will appear in "User Presets"

### Lightroom CC:
1. Open Lightroom
2. Go to Presets panel
3. Click "..." menu
4. Select "Import Presets"
5. Choose the `.xmp` file

### Photoshop (Camera Raw):
1. Open image in Camera Raw
2. Click preset icon (three lines)
3. Click "Import Profiles and Presets"
4. Choose the `.xmp` file
5. Preset will appear in Presets panel

## Preset Files

- `AVA_VISIONARY.xmp` - Minimal, premium, future-forward
- `AVA_CREATOR.xmp` - Bold, fast, energetic
- `AVA_ALPHA_KREW.xmp` - Authority, unity, professional
- `AVA_STORYTELLER.xmp` - Human, authentic, emotional

## Usage

1. Import preset to your editing software
2. Apply to selected images
3. Fine-tune as needed (exposure, crop, etc.)
4. Maintain line aesthetic consistency

## Notes

- Presets are starting points
- Fine-tune per image
- Maintain consistency within each line
- Export at correct resolution (300 DPI for print, 72 DPI for web)
