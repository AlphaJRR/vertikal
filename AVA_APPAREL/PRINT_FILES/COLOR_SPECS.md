# Color Specifications - AVA Apparel Drop 001

## Print Colors by Line

### VISIONARY
- **Primary Print Color:** White (PMS White / #FFFFFF)
- **Alternative:** Gold Foil (PMS 871 / #D4AF37)
- **Background Garment:** Black, Washed Black, Dark Grey

### CREATOR
- **Primary Print Color:** White (PMS White / #FFFFFF)
- **Accent Color:** High contrast (Red #FF0000, Blue #0066FF, or Yellow #FFD700)
- **Background Garment:** Black, Washed Black, Dark Grey

### ALPHA KREW
- **Primary Print Color:** White (PMS White / #FFFFFF)
- **Alternative:** Silver (PMS 877 / #C0C0C0)
- **Background Garment:** Black, Washed Black, Dark Grey

### STORYTELLER
- **Primary Print Color:** Soft White (#F5F5F5) or Muted Tone
- **Background Garment:** Black, Washed Black, Dark Grey

## RGB Values
- White: RGB(255, 255, 255)
- Gold: RGB(212, 175, 55)
- Silver: RGB(192, 192, 192)
- Soft White: RGB(245, 245, 245)

## CMYK Values (for print)
- White: CMYK(0, 0, 0, 0)
- Gold: CMYK(0, 17, 74, 17)
- Silver: CMYK(0, 0, 0, 25)
- Soft White: CMYK(0, 0, 0, 4)

## Pantone Codes (if using spot colors)
- White: PMS White
- Gold: PMS 871 C
- Silver: PMS 877 C

## Print Method Notes
- **DTG:** RGB colors converted automatically
- **Screen Print:** Use Pantone spot colors for accuracy
- **White Underbase:** Required for all dark garments (black, washed black, dark grey)
