# Print Placement Guide - Visual Reference

## Front Print Placement

```
                    [NECKLINE SEAM]
                         |
                         | 2" (5cm)
                         |
                    ┌─────────┐
                    │         │
                    │  PRINT  │ 4-5" wide (10-13cm)
                    │  AREA   │ 1.5-2" tall (4-5cm)
                    │         │
                    └─────────┘
                         |
                         |
                    [GARMENT BODY]
```

**Specifications:**
- Top edge: 2" (5cm) below neckline seam
- Width: 4-5" (10-13cm) depending on line
- Height: 1.5-2" (4-5cm) depending on line
- Centered horizontally on garment
- Safe zone: 0.25" (6mm) inside all edges
