## 📋 PRESET CREATION STEPS

### **In Lightroom:**
1. Edit one image to match preset settings
2. Go to Develop module
3. Click "+" next to Presets panel
4. Name: "AVA - VISIONARY" (or line name)
5. Check all settings you want included
6. Click "Create"

### **In Photoshop (Camera Raw):**
1. Open image in Camera Raw
2. Apply settings
3. Click preset icon (three lines)
4. Click "New Preset"
5. Name: "AVA - VISIONARY"
6. Select settings to include
7. Click "OK"

### **Sharing Presets:**
- **Lightroom:** Export as `.lrtemplate` or `.xmp`
- **Camera Raw:** Export as `.xmp`
- **Location:** Save to `AVA_APPAREL/PRESETS/` folder

## 🎯 USAGE GUIDELINES

### **Workflow:**
1. Import images to Lightroom/Photoshop
2. Apply line-specific preset
3. Fine-tune per image (exposure, crop, etc.)
4. Export with correct settings

### **Fine-Tuning:**
- Presets are starting points
- Adjust exposure per image
- Crop for composition
- Remove distractions
- Maintain line aesthetic

### **Consistency:**
- Use same preset for all images in line
- Minor adjustments OK
- Major deviations = wrong line
