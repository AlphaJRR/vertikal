## 2. Database tables (004)

| Table | Key columns | Notes |
|---|---|---|
| `events` | `photographer_id`, `access_code`, `qr_token`, `event_type`, `status` | `qr_token` = `encode(gen_random_bytes(12),'hex')` |
| `event_photos` | `storage_path` (originals), `thumb_path` (previews) — both NOT NULL | Row inserted by `process-photo` edge fn AFTER both paths exist |
| `attendees` | `user_id`, `redeem_code`, `first_name`, `last_name`, `email`(opt), `phone`(opt), `deleted_at` | `redeem_code` auto-set by 005 trigger |
| `attendee_interests` | `attendee_id`, `interest` | Optional; never gates gallery |
| `photo_assignments` | `photo_id`, `attendee_id` | THE privacy join — no row = no access |
| `consent_log` | `attendee_id`, `consent_type` (photo_release/marketing/terms/age_confirm), `granted` | Written by consent screen |
| `install_events` | `event_id`, `type` (qr_scan/install/account_created) | Attribution only |
| `event_operators` | `user_id` | Admin-granted only; users cannot INSERT |
| `orders`, `order_items`, `print_jobs`, `event_products`, `discount_codes` | — | In schema but **UNUSED in v1**. Payment is offline. |

## 3. RLS privacy model (#1 acceptance criterion)

```sql
-- Attendee sees ONLY photos with an explicit photo_assignment row
-- AND attendee.deleted_at IS NULL
create policy photos_attendee_read on event_photos for select using (
  exists (
    select 1 from photo_assignments pa
    join attendees a on a.id = pa.attendee_id
    where pa.photo_id = event_photos.id
      and a.user_id = auth.uid()
      and a.deleted_at is null
  )
);
```

**Never gate privacy in app code alone.** RLS + signed URLs are the enforcement. App code is courtesy only.

## 4. Storage buckets (both PRIVATE — no public URLs ever)

| Bucket | Content | Path convention |
|---|---|---|
| `event-originals` | Full-res originals uploaded by photographer | `{eventId}/{itemId}/original` |
| `event-previews` | Watermarked thumbnails generated by process-photo | `{eventId}/{itemId}/thumb` |

Attendees access photos exclusively via signed URLs minted by `mint-download-url` edge fn after DB assignment check.

## 5. Edge functions (3 active in v1)

| Function | Trigger | Does |
|---|---|---|
| `process-photo` | App calls after upload to event-originals | Downloads original → generates 400px thumb + watermark via imagescript → uploads to event-previews → **INSERTs event_photos row** |
| `mint-download-url` | App calls per photo | Verifies `photo_assignments` + `deleted_at IS NULL` → returns signed URL (TTL 1h) |
| `delete-account` | Settings → Delete my account | Soft-deletes attendees (sets `deleted_at`), nulls PII fields, removes originals from storage, calls `auth.admin.deleteUser` |

Deleted Stripe functions: `create-print-order`, `stripe-webhook` — do not re-add.

## 6. Offline payment / redeem-code model

**Payment happens at the event (cash/card reader/Zelle). No in-app payment of any kind.**

Flow:
1. Photographer creates attendee → `set_redeem_code` trigger auto-generates a 6-char code (e.g. `A3K7M9`)
2. Photographer assigns photos → hands buyer the code
3. Buyer: scan QR → sign in → enter code → `supabase.rpc('redeem_attendee_code', { p_code })` → sets `attendees.user_id = auth.uid()` → RLS resolves gallery
4. RPC errors: `'Invalid code'` or `'Code already claimed'` (a different user claimed it first)

**Do not add Stripe, IAP, in-app purchase, or any price UI.** Digital downloads are always free.

## 7. Auth — OTP-only sign-up (no password sign-up)

`signUpWithPassword` was removed. It sent a link-based confirmation email whose URL used Supabase's `Site URL` (defaulted to localhost) → dead page on mobile.

**Current flow:**
- New accounts: `signInWithOtp({ shouldCreateUser: true })` → user enters 6-digit code → `verifyOtp` → signed in. No link, no redirect, works on first install.
- Returning sign-in: password OR OTP (user's choice).
- After auth: check `profiles.tos_accepted_at`; if null → route to `/consent`.

Supabase Dashboard config needed (docs/SUPABASE_EMAIL_SETUP.md):
- Site URL → `https://alphavisualartists.com`
- Add redirect URLs: `ava://**`, `exp://192.168.*/**`
- Set up Resend SMTP for branded email sender

## 9. Operator role gating (006)

```
event_operators table → admin-only INSERT (service role)
is_event_operator() RPC → called by useIsOperator hook → defaults FALSE on error
events_operator_insert policy → INSERT INTO events requires is_event_operator() = true
```

**useIsOperator** — fails closed (returns false while loading, on error, on sign-out).
**useOperatorGuard** — used in create-event, event detail, upload, assign, create-attendee, dashboard. Redirects non-operators after loading resolves.

Events tab branches:
- `loading` → neutral skeleton (no role-specific UI)
- `isOperator` → OperatorHome (event list, create button)
- `!isOperator` → AttendeeHome (redeem + gallery only)
